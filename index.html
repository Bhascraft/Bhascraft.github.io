Server Features

Two gamemodes joined by a shared Hub, a custom-generated world, and a playtime-based rank system.

Survival

An open, mostly rules-free world on a custom-generated map. Griefing, stealing, and PVP are all allowed.

Creative

Claim a 100×100 plot with /plot auto and build freely with WorldEdit tools.

  • Rank Progression — 5 playtime-based ranks (Beginner → Legend) unlock new commands as you play, up to 300 hours.
  • Custom World Generation — Survival's map is built with Terralith and a set of extra structure packs.
  • Proximity Voice Chat — Talk to nearby players with the Simple Voice Chat mod.
  • Central Hub — A shared lobby connects every gamemode and the leaderboard.

Frequently Asked Questions

Do I need to install any mods?

No mods are required to play. Installing the Simple Voice Chat mod is optional, and only needed if you want proximity voice chat.

Is there a land claiming system?

Not in Survival, where griefing is allowed — but Creative uses protected 100×100 plots.

How do ranks work?

Ranks unlock automatically based on total playtime — Beginner (0h), Master (25h), Veteran (50h), Champion (150h), and Legend (300h) — each unlocking additional commands.

Is there an economy?

Not currently — Survival has no economy system in place.
