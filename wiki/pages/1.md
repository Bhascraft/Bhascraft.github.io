# Bhascraft Docs

## Welcome

Welcome to **Bhascraft** — a **Survival** and **Creative** Minecraft server. Whether you want to carve out a base in Survival or build freely on your Creative Plot, hopefully there will be something here!

When you first join, you'll land in the **Hub** — a central lobby that connects everything together. From here you can jump into either gamemode or check out the leaderboard.

![Hub screenshot](images/image_1781008239149_0.webp)

There's proximity **voice chat** if you install the client mod. Browse the sidebar for Survival, Creative, and everything else.

## The Reset

On **31 May 2026**, Bhascraft went offline after a data-loss incident. It stayed down while the server was rebuilt, optimized, and reset. Here's what changed:

- **Survival was regenerated from scratch** — a brand new map, pregenerated ahead of time (rather than generated on the fly as players explore) to cut down on lag, using Terralith and several structure packs. See the [Survival](#survival) page for details.
- **Creative was *not* reset** — existing plots and builds carried over untouched.
- **All playtime and playtime-rank progress was reset to 0.** The rank thresholds and rewards themselves are unchanged (see below) — everyone just starts again from Beginner.
- **PVP and SkyBlock were removed** from the server entirely. Their old docs have been kept for reference on the [Archive](#archive) page.
- **Bedrock Edition support (Geyser) was removed** — Bhascraft is Java Edition only for now.
- The server was generally **debloated and optimized** — a number of unused plugins were removed, and some were replaced with lighter alternatives. See the [Technical Info](#technical-info) page for specifics.
- New server icon and MOTD.

## Mechanics

### AFK System

The **AFK** system prevents players from gaining playtime if they haven't done anything on the server for more than **30 seconds**. This stops players from leaving their accounts AFK to farm ranks and leaderboard positions. You can also trigger it manually with `/afk`.

The AFK detector can be spoofed by most things (e.g., water circles, piston movers, and AFK-spoofer mods). If the AFK system gets tricked and abused, the detection will be made more strict — hopefully this won't need to happen.

### MiniMessage Formatting

**MiniMessage** is a way of formatting text on a Paper Minecraft server. It works by adding tags before and after your text to change its colour and effects.

The tags look like this: `<blue>`, `<rainbow>`, `<bold>` and `<#0000FF>`

It can be used in most places where you can enter text (like **/nick**), with the exception of normal chat. More info can be found on the [Paper MC Docs](https://docs.papermc.io/adventure/minimessage/).

## Voice Chat

Bhascraft has **Simple Voice Chat**, which allows players with the client-side mod to use proximity and group voice chat. Simply install the mod, and it will automatically connect to the server's voice chat plugin.

Mod: [Simple Voice Chat on Modrinth](https://modrinth.com/mod/simple-voice-chat)
Plugin: [Simple Voice Chat Plugin on Modrinth](https://modrinth.com/plugin/simple-voice-chat)
