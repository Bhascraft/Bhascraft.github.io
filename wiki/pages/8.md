# Technical Info

## Hardware

The server runs on a **Lenovo ThinkCentre M910q**.

### System Overview

- **Model:** Lenovo ThinkCentre M910q (10MUS0C500)
- **Motherboard/Bus:** Lenovo 310B (Intel Q270 Chipset)

### Processor (CPU)

- **Model:** Intel® Core™ i5-7500T @ 2.70 GHz (7th Generation)
- **L1 Cache:** 256 KiB
- **L2 Cache:** 1 MiB
- **L3 Cache:** 6 MiB

### Memory (RAM)

- **Total Capacity:** 16 GiB
- **Configuration:** 2 × 8 GiB slots
- **Type:** SODIMM DDR4 Synchronous Unbuffered (2400 MHz)

### Storage

- **Drive 1 (NVMe SSD):** 128 GB Samsung MZVLW128HEGR
- **Drive 2 (SATA SSD):** 232 GiB Samsung SSD 850 *(server data disk)*

### Other

- **GPU:** Intel® HD Graphics 630 (/dev/fb0)
- **Audio:** Intel 200 Series PCH HD Audio
- **Network:** Intel® Connection (2) I219-LM (Gigabit LAN)

### Removed: Cross-Play (Bedrock)

Geyser-Spigot and Floodgate, which used to let Bedrock Edition players connect, have been removed. Bhascraft is Java Edition only for now.

## Server Execution

The server runs inside a custom Docker container. For more information on Docker, see [docker.com](https://www.docker.com/).


The server is allocated **12 GB** of RAM. Docker handles automatic restarts and keeps the server isolated from the host system.
