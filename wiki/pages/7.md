# Commands

All commands available to players on Bhascraft. Commands marked with a rank require that rank or higher.

## General Commands

Available to every player regardless of rank:

| Command | Description |
|---------|-------------|
| `/playtime` | Displays your total playtime on the server. |
| `/warp [name]` | Teleports you to a public server warp location. |
| `/warp list` | Lists all available public warp destinations. |
| `/afk` | Manually marks you as AFK, stopping your playtime from counting up. |

## Creative Plot Commands

> **Tip:** You can use `/p` as a shortcut for `/plot`.

| Command | Description |
|---------|-------------|
| `/plot auto` | Automatically finds and claims the nearest empty plot. |
| `/plot claim` | Claims the plot you are currently standing on. |
| `/plot home` | Teleports you to your plot. |
| `/plot clear` | Resets all blocks on your plot to the default flat state. |
| `/plot delete` | Clears and unclaims your plot entirely. |
| `/plot list` | Lists plots based on specified criteria. |
| `/plot visit [player]` | Teleports you to another player's plot. |
| `/plot add [player]` | Allows a player to build on your plot while you are online. |
| `/plot trust [player]` | Gives a player permanent build access to your plot. |
| `/plot remove [player]` | Revokes build access from an added or trusted player. |
| `/plot confirm` | Confirms a destructive action such as clearing or deleting. |

## WorldEdit Commands

WorldEdit is available in the Creative world only.

| Command | Description |
|---------|-------------|
| `//wand` | Gives you the region selection tool (usually a wooden axe). |
| `//pos1` / `//pos2` | Sets selection position 1 or 2 at your current eye location. |
| `//hpos1` / `//hpos2` | Sets selection position 1 or 2 at the block you are looking at. |
| `//set [block]` | Fills your entire selection with a specific block. |
| `//replace [from] [to]` | Replaces one block type with another inside your selection. |
| `//walls [block]` | Builds a perimeter wall around the edges of your selection. |
| `//faces [block]` | Creates a hollow box (walls, floor, and ceiling) around your selection. |
| `//copy` | Copies your selection to your clipboard. |
| `//cut` | Removes your selection and copies it to your clipboard. |
| `//flip` | Flips your clipboard selection directionally. |
| `//rotate [angle]` | Rotates your clipboard selection by a given number of degrees. |
| `//paste` | Pastes your clipboard relative to your current position. |
| `//undo` | Reverts your last WorldEdit action. |
| `//redo` | Re-applies your last undone WorldEdit action. |

## Rank-Locked Commands

### Master Rank

| Command | Description |
|---------|-------------|
| `/msg [player] [message]` | Sends a private direct message to another online player. |

### Veteran Rank

| Command | Description |
|---------|-------------|
| `/trash` | Opens a temporary disposal UI where you can destroy items permanently. |

### Champion Rank

| Command | Description |
|---------|-------------|
| `/skull` | Spawns a decorative player head. |
| `/skull [player]` | Spawns a skull with a specified player's skin. |

### Legend Rank

| Command | Description |
|---------|-------------|
| `/nick [nickname]` | Sets a custom chat display nickname. |
| `/nick [color/format]` | Applies MiniMessage formatting or colour to your nickname. |
| `/pp` or `/playerparticles` | Opens the particle effects menu to apply cosmetic effects. |
