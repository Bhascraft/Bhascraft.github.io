# Technical Info

## Hardware

The server runs on a **Lenovo ThinkCentre M910q**.

### System Overview

- **Model:** Lenovo ThinkCentre M910q (10MUS0C500)
- **Motherboard/Bus:** Lenovo 310B (Intel Q270 Chipset)

### Processor (CPU)

- **Model:** Intel® Core™ i5-7500T @ 2.70 GHz (7th Generation)
- **L1 Cache:** 256 KiB
- **L2 Cache:** 1 MiB
- **L3 Cache:** 6 MiB

### Memory (RAM)

- **Total Capacity:** 16 GiB
- **Configuration:** 2 × 8 GiB slots
- **Type:** SODIMM DDR4 Synchronous Unbuffered (2400 MHz)

### Storage

- **Drive 1 (NVMe SSD):** 128 GB Samsung MZVLW128HEGR
- **Drive 2 (SATA SSD):** 232 GiB Samsung SSD 850 *(server data disk)*

### Other

- **GPU:** Intel® HD Graphics 630 (/dev/fb0)
- **Audio:** Intel 200 Series PCH HD Audio
- **Network:** Intel® Connection (2) I219-LM (Gigabit LAN)

## Plugins

Bhascraft uses the **Paper MC** plugin loader. More info at [papermc.io](https://papermc.io/).

### Chat & Display

| Plugin | Description |
|--------|-------------|
| CarbonChat | Manages chat formatting, channels (local, global, plot chat), and direct messaging. |
| FancyHolograms | Creates floating text, images, or item displays in the world to show info or welcome messages. |
| FancyNpcs | Adds customisable NPCs that can talk, look at players, or execute commands when clicked. |
| MiniMOTD | Customises the message players see on the server list before joining. |

### World & Game Modes

| Plugin | Description |
|--------|-------------|
| BentoBox & BentoBox-BSkyBlock | The framework used to generate, manage, and protect player SkyBlock islands. |
| PlotSquared | Generates the creative plot world and handles plot ownership and claiming. |
| Multiverse-Core | Runs multiple separate worlds simultaneously on one server instance. |
| Multiverse-Inventories | Separates player inventories, health, and XP between different worlds. |
| Multiverse-Portals | Creates physical in-game portals to teleport players between worlds. |

### Core Mechanics & Management

| Plugin | Description |
|--------|-------------|
| LuckPerms | The primary permission manager, handling ranks, prefixes, and command access. |
| Essentials & EssentialsSpawn | Provides core utility commands (teleportation, warps, homes, messaging) and spawn management. |
| Vault | A bridge plugin linking chat, permissions, and economy systems together. |
| ViaVersion | Allows players on newer Minecraft versions to connect to the server. |
| Statz | Tracks player statistics such as playtime, blocks broken, and deaths. |
| aJLeaderboards | Pulls stat data to display leaderboards on signs, holograms, and in the tab list. |

### World Editing & Protection

| Plugin | Description |
|--------|-------------|
| FastAsyncWorldEdit (FAWE) | A high-performance WorldEdit for large block operations without server lag. |
| WorldGuard & WorldGuardExtraFlags | Defines protected regions (like spawns) and adds extra zone properties. |

### Cross-Play (Bedrock)

| Plugin | Description |
|--------|-------------|
| Geyser-Spigot & Floodgate | Allows Bedrock Edition players (mobile, console, PC) to join the Java Edition server. |

### Player Features & Cosmetics

| Plugin | Description |
|--------|-------------|

| voicechat | Adds proximity-based voice chat so nearby players can talk with microphones. |

| Plugin | Description |

## Server Execution

The server runs inside a custom Docker container. For more information on Docker, see [docker.com](https://www.docker.com/).

### Dockerfile

```dockerfile
FROM amazoncorretto:26-alpine3.20
VOLUME /tmp
RUN mkdir -p /server
WORKDIR /server
EXPOSE 25565
EXPOSE 8100
ENTRYPOINT ["sh", "-c", "exec java -Xmx7000M -Xms7000M -jar /server/paper.jar"]
```

The server is allocated **7,000 MB** of RAM. Docker handles automatic restarts and keeps the server isolated from the host system.

### Docker Run Command

```bash
docker run -p 25565:25565 -p 8100:8100 -p 24454:24454/udp -p 19132:19132/udp -d \
  -e FORCE_REDOWNLOAD_CA_CERTIFICATES=true \
  -e JAVA_TOOL_OPTIONS="-Djava.net.preferIPv4Stack=true" \
  -v /etc/timezone:/etc/timezone:ro \
  -v /etc/localtime:/etc/localtime:ro \
  --name bhascraft --restart always \
  --mount type=bind,src=/mnt/ssd/bhascraft-data/,dst=/server \
  hydrogenrocket/bhascraft
```

Server data is bind-mounted to the host filesystem so it can be edited easily by users and plugins without needing to access the container directly.
