Bhascraft Docs

Welcome

Welcome to Bhascraft, a multi-gamemode Minecraft server! Upon joining the server, you will spawn in the Hub (lobby).

From the Hub you can access all the gamemodes:

⚔️
SurvivalPvP, griefing, and open-world survival.
 🎨
CreativePlot-based creative building with WorldEdit.
 🏝️
SkyblockIsland survival with a team system.
 🗡️
PVPFFA kit-based PVP arena.

Mechanics

AFK System

The AFK system prevents players from gaining playtime if they haven't done anything on the server for more than 30 seconds. This stops players from leaving their accounts AFK to farm ranks and leaderboard positions.

The AFK detector can be spoofed by most things (e.g., water circles, piston movers, and AFK-spoofer mods). If the AFK system gets tricked and abused, the detection will be made more strict — hopefully this won't need to happen.

MiniMessage Formatting

MiniMessage is a way of formatting text on a Paper Minecraft server. It works by adding tags before and after your text to change its colour and effects.

The tags look like this: <blue>, <rainbow>, <bold> and <#0000FF>

It can be used in most places where you can enter text (like /nick), with the exception of normal chat. More info can be found on the Paper MC Docs.

Bedrock Edition

The server has the Geyser MC plugin, which allows players from Bedrock Edition to connect to Bhascraft. Since Bedrock is available on consoles, tablets/iPads, and PCs, the connection method varies by platform.

PC / Pocket Edition

Connecting from Pocket Edition or PC is straightforward:

  1. Press Play.
  2. Navigate to the Servers tab.
  3. Scroll past the featured servers and press Add Server +.
  4. Enter the following details:
    Server Name: Anything you like
    Server Address: 51.148.188.225
    Port: 19132 (default)

Console

Joining from a console is more involved, because consoles don't have a direct "add server" option. You need to use a third-party tool called BedrockConnect to redirect your console to Bhascraft.

Nintendo Switch
  1. Go into your console's internet settings and set the primary DNS to 104.238.130.180 and the secondary DNS to 8.8.8.8.
  2. Open Minecraft and go to the Servers tab.
  3. Join a redirect-compatible featured server to open BedrockConnect.
  4. Find Bhascraft in the server list and connect.

Redirect-compatible servers: Mineville, Lifeboat, Enchanted, Galaxite, The Hive

Voice Chat

Bhascraft has Simple Voice Chat, which allows players with the client-side mod to use proximity and group voice chat. Simply install the mod, and it will automatically connect to the server's voice chat plugin.
